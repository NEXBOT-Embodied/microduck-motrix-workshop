# 教师镜像与并发验收

当前状态：本机已使用真实 MotrixSim SDK 完成教师预训练和行走试验，已有真实 checkpoint、录像和指标；课堂 reference / starter 尚未验收登记。云端镜像、普通学员账号闭环与 50 人独立训练仍待平台实测。本包验证范围见 [资料包验证记录](../../05_交接与验收/资料包验证记录.md)。

## 发布门槛

| 验收项 | 做法与证据 | 当前状态 |
|---|---|---|
| 单变量真实生效 | 从实际官方 factory 生成 task dataclass，改倍率并核对 `penalty_action_rate.weight`；原配置不变 | 离线可验证，见 checks |
| 依赖闭包 | 冷启动镜像不联网安装，直接运行 config/check | 待云实例实测 |
| SDK/模型 | `check --runtime` 创建 1 环境、reset，确认 55/58/14 实际空间与真实网格 | 本机真实reset已验证；待云镜像复测 |
| 行走参考 | reference 真实回放 3 次，记录摔倒、静止和指令跟踪；保存本机真实视频 | 已有训练checkpoint与3个seed评估；课堂reference待验收登记 |
| 学员续训 | 复制同一 SHA 的 starter，实际新增采样和 critic/actor 更新，生成独立 checkpoint 与日志，重新回放 | 待实测 |
| 受控评估 | 倍率 1.0 与实验倍率使用同 starter/seed/预算，固定命令 preset；保存实际评估设置与报告 | 配置/factory 离线可验证，真实步态待实测 |
| 算法结构 | 策略/价值网络、归一化、动作顺序与起步权重一致；导出做数值 parity | 静态契约已列，运行待实测 |
| 图形窗口 | 每个云桌面中可看见 MotrixSim，确认鼠标视角与可用操作；不要承诺未验证的拖拽施力 | 待实测 |
| 离屏录像 | `play --record` 真实输出可播放 mp4，记录真实时间和画面 | 本机已有7段真实原片；待云端路径复测 |
| 学员隔离 | 2 个账号相同文件名训练，不能互改彼此工程；重连后文件仍在 | 待平台确认/实测 |
| 50 人容量 | 每人各 1 个训练进程和课堂设定 env 数，并可查看结果 | 待压测 |
| 备用平台 | 同版模板可启动，reference/starter 同 SHA；不临时安装 | 待实测 |

默认课堂 `32 env` 只是起点；一次 50 人会产生总计 1,600 个仿真环境以及 50 个策略训练进程。不能据此直接推定服务器能承受，也不能把环境批次数当作学员人数。

## 分级压测
