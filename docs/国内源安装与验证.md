# 国内源安装与验证

此页适用于课程仓库内置的 MotrixLab 固定版本。Windows 需要 Git for Windows（含 Git Bash），Ubuntu 需要 Bash、Git、curl、unzip 和 tar。Ubuntu 可使用系统已配置的 apt 源安装基础工具。下载 GitHub 工程时，Windows 用短目录并加 `git -c core.longpaths=true clone`。

| 下载项 | 课程安装入口的来源 |
|---|---|
| uv 与通用 Python 包 | 清华 PyPI 镜像 |
| Python 3.12 | 复用现有 3.12，或从南京大学镜像获取固定的 3.12.16 构建。Windows 也可手动安装[清华镜像中的官方 Python x64 安装包](https://mirrors.tuna.tsinghua.edu.cn/python/3.12.8/python-3.12.8-amd64.exe) |
| PyTorch | 南京大学 PyTorch 镜像，按 `cpu` 或 `cuda` 选择 |
| MotrixSim 开发版 | 谋先飞官方包源 `pypi.motphys.com` |
| 工程、模型和 Git LFS | NEXBOT 的 GitHub 仓库。网络受限时，可先在能访问 GitHub 的可信机器完整下载，再将工程或已校验的 Git bundle 交给学员 |

在仓库根目录运行相应平台的命令。

| 系统 | 普通虚拟机 | CUDA 训练 |
|---|---|---|
| Windows PowerShell | `powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\install_course.ps1 -Backend cpu` | 同一命令使用 `-Backend cuda` |
| Ubuntu Bash | `bash tools/install_course.sh --backend cpu` | 同一命令使用 `--backend cuda` |

如镜像不可用，可显式加 Windows 的 `-Upstream` 或 Ubuntu 的 `--upstream`，切换到原始包源。请把两次安装的日志分开记录。安装后，检查所用 Python、依赖与教学权重。

```powershell
.\tools\lesson.cmd check --brief --allow-cpu
.\tools\lesson.cmd train --steps 256 --constraints configs/walking_constraints.yaml --dry-run
```

```bash
bash tools/lesson.sh check --brief --allow-cpu
bash tools/lesson.sh train --steps 256 --constraints configs/walking_constraints.yaml --dry-run
```

CPU 检查可在普通虚拟机运行。窗口和视频还需要可用的图形后端。CUDA 课堂训练需要虚拟机实际识别 NVIDIA CUDA 设备。用[虚拟机验证提示词](虚拟机Codex验证提示词.md)分别报告四项的结果。
