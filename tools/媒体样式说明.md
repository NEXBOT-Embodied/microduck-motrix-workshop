# 真实训练录像的教学标注样式

`style_training_media.py` 为真实 MotrixSim 录像添加软件风格的外围教学标注。画面使用深灰底板、中性灰分隔线、浅色文字和细蓝色高亮。右侧先展示实际算法 FastSAC、训练采样迭代（global_step）、梯度更新计数（update_idx）和评价命令，再用“平衡 / 前进 / 平滑”引导学生看步态。UTC 时间、随机种子、FPS 与训练来源路径等追溯信息保留在 manifest 中，不占用课堂画面。它不伪造谋先飞原生窗口、菜单、按钮、运行状态或官方背书。

顶部保留“教学标注版”，底部展示“观察：是否站稳？是否跟随前进命令？动作是否平滑？”和“行走效果待观察”。画面不展示 run/checkpoint 长路径或编码完整性声明，也不会因媒体加工成功就显示行走合格。源报告的 `walking_verified` 原值仍按严格布尔值记录在 manifest；即使源报告为 true，画面也保留观察提示，不由标注工具做课堂效果判定。

原始 `960×540` 视频完整放在 `1280×720` 画布的 `(20,88)`，不裁切、不缩放、不变速、不改动作；FFmpeg 只做外围底板与原片 overlay。原视频和 report 保留原路径、原内容，输出写入尚不存在的新目录。编码为 H.264/yuv420p，会重新压缩像素；“不改动作”指保持原片的帧序、帧数和 FPS，不代表压缩后字节逐位相同。

## 使用

使用已经包含 Pillow 和 imageio-ffmpeg 的教师运行环境。本工具不安装依赖、不运行仿真，也不触发训练。

```powershell
$stage = './outputs/recordings/某次已验证录像/01-step-1000-update-3748'
$videoDigest = (Get-FileHash -LiteralPath "$stage/walking.mp4" -Algorithm SHA256).Hash.ToLowerInvariant()
& './outputs/.venv/Scripts/python.exe' `
  './tools/style_training_media.py' `
  --stage-dir $stage `
  --output-dir './outputs/recordings/styled-step1000-v1' `
  --expected-video-sha256 $videoDigest
```

旧阶段报告没有 `video.sha256` 字段，因此需要显式传入调用前已核对的原片 SHA256；新报告已有该字段时可以省略参数。二者同时提供时必须一致。加工前后均重新计算原片和 report 的 SHA256，任何变化都会使 manifest 标记失败。

`--preview` 在画面和 manifest 中明确写“样式预览”，用于已有 smoke 录像的排版检查。`smoke-step200-compat1` 的首帧黑屏和未验收行走状态不能因添加样式变成正式课堂成品。正式成品应选择经过教师确认的真实录像；工具不会把 `walking_verified=false` 自动改成 true。

可用 `--poster-frame 75` 选择海报对应的实际零基帧；默认使用原片中间帧。海报保留原帧全部 `960×540` 像素，并记录帧号及时间。字体默认 `C:/Windows/Fonts/msyh.ttc`；其他电脑可通过 `--font` 指定可用中文字体文件。

## 输出与验收

每个新目录生成 `teaching.mp4`、`poster.png`、`backdrop.png` 和 `manifest.json`。manifest 保留源 report 路径与 hash、原片 hash、source 训练来源、checkpoint hash、实际训练计数、评价设置、原片 FPS/时长和真实阶段起止时间；另记加工时间和画面观察文案，避免将两种时间混淆。源报告 `started_utc` 在导入运行库与源校验之前生成，因此记为 `stage_started_utc`，不把它称为第一帧录制的精确时间，也不在画面展示。

工具重新完整解码原片和输出视频，检查帧数、FPS、分辨率及解码结束状态。输出必须是 `1280×720` 且与原片帧数/FPS 相同；海报重新打开检查尺寸，并逐像素核对原片区域。`success` 仅表示该媒体加工与完整性检查成功，不表示策略已经通过行走验收。

输入 report 的 `success` 必须严格为 true、status 必须 completed，且视频已标记完整解码。source 必须为 FastSAC/MotrixSim 的真实训练策略记录，source 与阶段 checkpoint/hash 及评价设置必须一致。本工具不重新读取或执行 checkpoint，只根据已验证报告保留来源。
