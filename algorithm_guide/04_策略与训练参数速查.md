# 策略与训练参数速查

来源为固定 MotrixLab 提交，任务覆盖优先于算法基线。课堂资源预设以 `configs/classroom.yaml` 为准；本表不是每位学员可以任意改动的配置清单。

## 学员只改一个实验因素

`configs/experiment.yaml` 中的动作变化惩罚倍数，校验器允许 0.25–4.0，课堂推荐选 **0.5 / 1.0 / 2.0** 之一。具体解释见 `configs/README.md`，校验实现见 `src/microduck_course/config.py`。

| 倍数 | 进入环境的标量权重 | 实验假设 |
|---:|---:|---|
| 0.5 | -0.25 | 可能更愿意做快速动作，也可能更抖 |
| 1.0 | -0.50 | 基线 |
| 2.0 | -1.00 | 可能更平滑，也可能牺牲速度或反应 |

这些是待验证预测，不是预定结果。不同种子和短训练时长可能掩盖差异；结论可以是“当前证据不足”。

## 网络结构与推理合同

| 类别 | 实际默认值 / 静态结构 | 含义 |
|---|---|---|
| Actor 输入 / 输出 | 55 / 14，输入维数须运行复核 | 观测到动作分布 |
| Actor 隐藏层 | 512 → 256 → 128 | 非简单三层全部 512 |
| Critic 特权观测 / 动作 | 58 / 14，拼接共 72 | 训练使用 |
| Critic 隐藏层 | 768 → 384 → 192 | 两个 Q 网络 |
| 激活 / 归一化 | SiLU / LayerNorm | 网络内部结构 |
| 动作分布 | tanh 高斯，log std ∈ [-5, 0] | 训练探索与边界映射 |
| 回报分布 | 101 atoms，[-20, 20] | C51 Critic，不是动作离散化 |
| 观测归一化 | 开启，Actor / Critic 独立 | 导出时必须保留 Actor 统计 |
| 位置动作缩放 | 0.5 rad / action-unit | 还需默认姿态、关节顺序与控制范围 |
| 物理 / 策略周期 | 0.005 / 0.02 s | 200 Hz / 50 Hz |

## 优化与经验池

| 真实字段 | 合并后的上游值 | 说明 |
|---|---:|---|
| `actor_learning_rate` | 0.0003 | Actor 学习率 |
| `critic_learning_rate` | 0.0003 | Critic 学习率 |
| `alpha_learning_rate` | 0.0003 | 熵温度学习率 |
| `weight_decay` | 0.001 | AdamW 权重衰减 |
| `gamma` | 0.97 | 长期奖励折扣 |
| `tau` | 0.125 | 目标网络软更新系数 |
| `alpha_init` | **0.01** | 任务覆盖基线 0.001 |
| `target_entropy_ratio` | **-0.1** | 按真实公式计算目标熵 |
| `batch_size` | **2048** | 任务覆盖基线 8192；与 num_envs 不同 |
| `num_updates` | **4** | 任务覆盖基线 8 |
| `policy_frequency` | 4 | 每 4 次 Critic 梯度更新才触发一次 Actor 更新 |
| `learning_starts` | 10 | 先采集若干 collector iterations |
| `buffer_size` | 1024 / env | 容量随并行环境数增大 |
| `num_steps` | 1 | n-step return 的 n |

训练基线默认启用异步、CUDA compile、AMP；课堂封装可以显式选择便于验证的同步执行预设并记录覆盖值。CPU 自动关闭部分 CUDA 特性。不能把未运行过的预设说成已满足课堂吞吐。

## 资源和教学预算不要混淆

上游 `num_envs=2048` 是一项大规模训练配方，**不是 2048 个学生，也不是每人默认配额**。课程配置的 `num_envs` 决定一个人的进程中有多少并行仿真环境；50 人同时训练应考虑 50 倍的进程、模型、经验池和显示负载。

学习迭代数不等于分钟数。15 分钟是课表目标，需在最终服务器测得吞吐后换算。没有可靠测量时先限制资源与迭代，标记“待实测”，不要承诺从零训练出稳定行走。

## 判断配置真正生效

查看 `config` 输出的静态预期 `derived.expected_action_rate_weight`，再对照运行目录：`course_config.json` 是课程设置，`task_effective.json` 是真实任务 factory 的映射结果，官方 `motrix_runs/.../task_config.yaml` 是最终算法配置。种子、起点 checkpoint、并行环境数和算法覆盖也应可追溯。若倍率为2而实际传入环境的奖励仍是 -0.5，本次修改即未生效，不能据此下学习结论。
