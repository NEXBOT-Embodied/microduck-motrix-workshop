# 05｜真实行走训练约束参考

本章把 Pollen 官方 MicroDuck 行走任务中的约束拆清楚，供本课的奖励设计、训练观察和故障排查使用。**参考值尚不等于本课已应用的参数，也不等于本课训练已通过验收。** 本课以固定 MotrixLab 任务为运行基线，学生最终在 MotrixSim 中观察结果；现场不安装环境，不做 Sim2Real。

资料核对日期：2026-11-08。主要依据为 [microduck_rl 固定提交](https://github.com/pollen-robotics/microduck_rl/tree/1e79c29c97d8b38aee9eefde77a545860ba7658e) 和其锁定的 `mjlab==1.3.0`。以下配置来自当前公开代码，不能冒充某一已发布 ONNX 的精确训练配置。

## 1. 四种约束要分开

| 机制 | 影响什么 | 课堂解释 |
|---|---|---|
| 物理与控制限制 | 关节范围、执行器输出、实际动力学 | “最多能到哪里、施加多大作用” |
| 奖励正则 | 越界、滑步、突变等行为的代价 | “能做，但这样做得分更低” |
| episode 终止 | 跌倒、NaN、边界、时间到之后复位 | “这次尝试何时结束” |
| 随机化与课程 | 物理、观测、命令和训练样本分布 | “训练时遇到哪些变化、何时增加难度” |

负奖励不是硬限制；源码有一个惩罚函数也不表示任务已经启用它。查看配置时要沿着基类、机器人覆盖项和最终任务逐层核对。

## 2. 关节、HOME 与动作

官方 walking 有14个驱动关节，左右腿各5个、头颈4个；`passive_*` 不进入策略动作。策略顺序是左腿、头颈、右腿，需按名字映射，不能按导入后的数组位置猜测。

官方动作是相对 HOME 的位置偏移：`target = HOME + action × scale`。Pollen walking 将基类 scale 从0.5覆盖为 **1.0**；本课固定任务采用 **0.5**。两者都输出14维不代表策略可互换。

官方机器人配置设置 `soft_joint_pos_limit_factor=0.9`，基类的 `dof_pos_limits` 代价为 **-1.0**。这与源 XML 的物理关节限位是两层机制。源 XML 的近似物理范围如下，模型换版时仍须逐关节重验：

| 关节 | Pollen 源 XML 范围（近似角度） |
|---|---|
| 左 / 右 hip_yaw | `[-25°,30°]` / `[-30°,25°]` |
| hip_roll | `±22°` |
| hip_pitch、knee、ankle | 各 `±90°` |
| neck_pitch | `[-90°,60°]` |
| head_pitch / head_yaw / head_roll | `±90°` / `±170°` / `±25°` |

HOME 不是全零：腿部 STAND2 包含约 `±0.4579 rad` 的 hip_pitch、`±0.4530 rad` 的 ankle 和 `±0.0049 rad` 的 knee。动作、关节位置观测和复位必须使用同一套 HOME。

本课可直接借鉴的原则是统一关节名、单位、零位、动作尺度与软硬限位，并记录触限比例。不能为了让机器人“看起来动得更大”随意扩大物理限位。

## 3. 力矩与平滑

Pollen 当前训练使用 **BAM M6 / XL330** 执行器；参考参数包括 `kp_fw=200`、电压6.5–8.2V、电压下限6.0V、压降增益0–0.2和 lag范围3–6。它包含电压、摩擦、延迟等动力学，不能当成 Motrix 位置 PD 的同名参数直接复制。

源 XML chosen_actuator 有 `kp=0.55`、`kv=0`、`forcerange=[-0.96,0.96]`。创建 BAM 后会改变执行器语义，不能据此断言 Pollen 所有训练都以0.96Nm统一硬限矩。本课应检查自身执行器的实际输出和饱和情况。

| 官方任务中的项 | 已核实的作用 |
|---|---|
| walking 的 `action_rate_l2` | 动作相邻步差值平方和；权重从-0.1逐步增加到-1.0，覆盖全部动作维度 |
| walking 的力矩幅值惩罚 | 当前有效配置没有启用 `joint_torques_l2`；该函数存在于源码，不能据此声称已启用 |
| VelStand 的 `joint_torque_rate_l2` | 额外权重-2e-3，计算 `sum((tau_t - tau_{t-1})²)`，没有除以dt；不是力矩幅值，也不是硬限幅 |

平滑权重课程以PPO迭代计数定义，不能直接套到 FastSAC 的训练步数。迁移前要核对控制周期、动作尺度、奖励是否乘dt、聚合方式和实际量级。

## 4. 速度目标与步态

当前 Pollen walking 的固定命令范围为 `vx ∈ [-0.4,0.4] m/s`、`vy ∈ [-0.3,0.3] m/s`、`wz ∈ [-1,1] rad/s`；15%环境采样原地转向，站立样本从2%逐步增加到25%。这组范围是上游参考，不是本课已测得的性能保证。

| 参考项 | 当前官方 walking 配置 |
|---|---|
| 平面速度 / yaw速度跟踪 | 权重均2.0；std分别 `sqrt(0.1)` / `sqrt(0.5)` |
| 躯干直立 | 权重2.0，std `sqrt(0.05)` |
| 腿部姿态 | 权重1.0，只选腿部，避免与头部命令互相对抗 |
| 脚腾空 | 权重3.0，窗口0.125–0.300s，运动命令下启用 |
| 离地高度 | 目标0.02m，读取足端相对地形高度 |
| 脚滑 | 权重-0.1，刻意较弱以免压制转向 |

课堂应先保留平地、低复杂度、固定种子的基线。学生做“跟踪速度”和“动作平滑”之间的单变量对比，同时看命令/实测速度、episode长度、触地与跌倒率。高reward、腿抖得快或短暂向前滑动都不足以证明稳定行走。

## 5. 碰撞与终止

Pollen 普通 walking 使用精简接触的 `robot_walk.xml`；VelStand 使用允许躯干和头部支撑的 full-collision 模型以学习倒地恢复。两种模型服务不同目标。

- 普通 walking 继承70°倾倒终止、20s episode、时间与地形边界检查，并额外启用 `nan_state` 立即复位。NaN不应继续进入网络更新。
- 脚传感器按左、右顺序匹配 `left_foot_collision` / `right_foot_collision`；自碰撞代价-1.0是奖励项，没有被写成“一切自碰撞立即终止”。
- VelStand 在先学走之后取消普通跌倒终止，让倒地成为恢复训练；持续倒地8s再回收。它还有专门的恢复门控和初始化课程，不能直接当作只教行走的默认任务。
- 本课 Motrix模型有自己的 `trunk_collision` 胶囊和官方终止定义。不能直接用Pollen的70°阈值或全碰撞恢复覆盖它，应核对本课实际 `terminated` / `truncated` 原因。

验收时要明确允许脚触地、如何认定身体跌倒、是否发生NaN，以及timeout和失败如何分别处理。不能为了录像连续而取消所有终止，也不能把重复跌倒复位当成稳定步态。

## 6. 随机化：先确认有效，再逐项增加

当前上游开启了脚摩擦0.7–1.3、躯干/头部重心变化、trunk质量惯量一致缩放0.95–1.05、BAM摩擦和armature倍率0.9–1.1、推扰、IMU旋转误差、编码器偏置及观测延迟。kp/kd、joint damping和初始基座倾角随机化当前关闭；列出range不等于开关已开启。

需要留意的实现细节：

- 质量与惯量通过pseudo-inertia一致变化，不能独立胡乱修改；随机化应从默认值重采样，避免反复累加。
- BAM下普通MuJoCo `frictionloss` 随机化可能不生效，需作用于实际执行器的摩擦模型。
- 当前头部body名单保留一个上游已注明的误归类 `bearing_roll`，实际为右髋连接体；不能原样照搬名称表。
- CoM范围应相对足底支撑面校核；上游记录过大的偏移会造成异常激进、难以稳定的步态。
- 当前观测噪声参考：gyro±0.03、gravity±0.01、joint_pos±0.001rad、joint_vel±0.25rad/s；速度观测额外延迟1个控制步。

本课没有现场Sim2Real任务。学生短训练应先保留简单可复现基线，教师可预先训练小扰动版本对照；不必一次开启电压、backlash、粗糙地形与全部硬件误差。

## 7. 什么算真实训练证据

官方README给出的量级是CUDA GPU、4096环境，约1–2小时形成可用步态；这是上游说明，不能当作本机或50人共享服务器的实测承诺。课堂几分钟训练用于观察变化，不保证从随机初始化获得稳定步态。

每份训练结果至少关联固定源码/模型/配置、随机种子、实际控制周期、训练步数和墙钟时间、终止原因、速度误差、跌倒率、动作变化/输出饱和、checkpoint hash。录像标明从零训练还是由自己的兼容starter续训；公开ONNX回放不能冒充本课训练所得。
